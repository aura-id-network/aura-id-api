# 🎴 AURA Cards API

**Aura Cards API** — это профессиональное серверное решение для управления цифровыми коллекционными картами, идентификации пользователей через Telegram и интеграции механик "Token Gating" (доступ к контенту по наличию NFT/карт).

Сервер обеспечивает полный цикл работы с картами: от генерации и хранения до верификации прав доступа на сторонних ресурсах.

## 🚀 Функциональность

* **Система идентификации:** Привязка карт к Telegram ID пользователя.
* **Token Gating:** API для проверки наличия карт для доступа к контенту на веб-сайтах.
* **Коллекции:** Поддержка авторских коллекций и динамическое ценообразование в Telegram Stars.
* **Access Keys:** Уникальные ключи доступа для безопасной проверки карт.
* **Аирдропы:** Система аирдропов для раздачи карт пользователям с ограниченным количеством и возможностью проверки доступности.
* **Автоматические миграции:** Встроенная система версионирования базы данных SQLite.

---

## 🛠 Технологический стек

* **Язык:** Python 3.8+
* **Фреймворк:** Flask
* **База данных:** SQLite (с поддержкой JSON-сериализации)
* **Утилиты:** `python-dotenv` (конфигурация), `flask-cors` (безопасность)

## ⚙️ Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/aura-id-network/aura-id-api.git
cd aura-id-api
```

### 2. Настройка виртуального окружения

Рекомендуется использовать виртуальное окружение для изоляции зависимостей проекта.

**Linux / macOS:**

```bash
python3 -m venv venv
source venv/bin/activate
```

**Windows:**

```bash
python -m venv venv
venv\Scripts\activate
```

### 3. Установка зависимостей

Установите все необходимые библиотеки одной командой:

```bash
pip install -r requirements.txt
```

### 4. Конфигурация

Создайте файл `.env` в корне проекта. **Этот файл содержит секреты и не должен попадать в репозиторий.**

```ini
# Пример содержимого .env

# Telegram Config
BOT_TOKEN=ваш_токен_от_botfather
ADMIN_IDS=123456789,987654321

# Database
DATABASE_URL=sqlite:///aura_pro.db

# Server Config
FLASK_HOST=0.0.0.0
FLASK_PORT=20196
API_BASE_URL=https://144.31.164.141.sslip.io
```

### 5. Запуск сервера

При первом запуске сервер автоматически создаст базу данных и применит необходимые миграции.

```bash
python src/api_server.py
```

Успешный запуск будет подтвержден сообщением в консоли:
`INFO:root:Starting AURA Cards API server on 0.0.0.0:20196`

## 📡 API Документация

**Публичный базовый URL:** `https://144.31.164.141.sslip.io`

Полная спецификация методов доступна в формате JSON по адресу `/api/docs`.

### 🩺 System

#### `GET /api/health`

Проверка статуса сервиса. Используется для мониторинга uptime.

**Ответ:**

```json
{
  "status": "healthy",
  "version": "1.1.0",
  "timestamp": "2026-01-19T18:00:00.000000"
}
```

### 🔐 Проверка доступа (Gating)

Эти методы используются внешними сайтами для проверки прав пользователя.

#### `POST /api/check-card`

Проверяет наличие **любой** активной карты AURA у пользователя.

**Request Body:**

```json
{ "telegram_id": 123456789 }
```

**Response (200 OK):**

```json
{
  "has_card": true,
  "card_count": 5,
  "cards": [
    {
      "id": 1,
      "card_number": 105,
      "name": "Member Card",
      "access_key": "XXXX-YYYY-ZZZZ"
    }
  ]
}
```

#### `POST /api/check-collection`

Проверяет наличие карты из **конкретной** коллекции. Требует `collection_access_key`.

**Request Body:**

```json
{
  "telegram_id": 123456789,
  "collection_access_key": "ABCD-EFGH-IJKL"
}
```

### 📚 Коллекции

#### `GET /api/collections`

Возвращает список всех опубликованных коллекций.

**Response:**

```json
{
  "collections": [
    {
      "id": 1,
      "name": "Founders Edition",
      "description": "Эксклюзивная коллекция для ранних пользователей",
      "star_price": 100,
      "link_id": "abc123eff",
      "card_count": 50
    }
  ]
}
```

#### `GET /api/collections/<id>`

Возвращает детальную информацию о коллекции, включая список всех карт.

### 🃏 Карты

#### `GET /api/cards/<access_key>`

Возвращает информацию о карте по её уникальному access key.

**Response:**

```json
{
  "card": {
    "id": 1,
    "card_number": 1,
    "name": "Card Name",
    "access_key": "ABCD-EFGH-IJKL",
    "registration_date": "01.01.2024",
    "collection_id": 1
  }
}
```

### 👤 Пользователи

#### `GET /api/user/<telegram_id>/cards`

Возвращает публичное портфолио пользователя (список всех его карт).

**Response:**

```json
{
  "user": {
    "telegram_id": 123456789,
    "card_count": 2
  },
  "cards": [ ... ]
}
```
